HomiQO is a responsive web platform designed to simplify the search for hostels,flats,and rooms for students and working professionals. 
The platform provides a seamless way to explore property listings and view detailed property information.

-Features
Interactive Property Cards: Easily browse through listings with essential details displayed at a glance.
Smooth Navigation: User-friendly interface with fast and intuitive browsing.
Cross-Platform Compatibility: Works flawlessly on desktops, tablets, and mobile devices.

-Technology Stack
Frontend: HTML, CSS, JavaScript
Responsive Design: Ensures a smooth experience across devices.

HomiQO provides a quick, easy, and convenient way for students and professionals to find suitable accommodations.
